# Java Collection Framework

This project provides comprehensive examples and tasks related to the Java Collection Framework. It is structured to help users understand and implement various collection types in Java, including Lists, Sets, Maps, Queues, and Deques.

## Project Structure

- **src/examples**: Contains example implementations demonstrating the usage of different collection interfaces.
  - `ListExamples.java`: Examples of List interface usage.
  - `SetExamples.java`: Examples of Set interface usage.
  - `MapExamples.java`: Examples of Map interface usage.
  - `QueueExamples.java`: Examples of Queue interface usage.
  - `DequeExamples.java`: Examples of Deque interface usage.

- **src/tasks**: Contains tasks that challenge users to implement functionality using the Java Collection Framework.
  - `Task01.java`: Task related to Lists.
  - `Task02.java`: Task related to Sets.
  - `Task03.java`: Task related to Maps.
  - `Task04.java`: Task related to Queues.
  - `Task05.java`: Task related to Deques.

- **src/solutions**: Contains solutions to the tasks outlined in the tasks folder.
  - `Solution01.java`: Solution for Task01 using Lists.
  - `Solution02.java`: Solution for Task02 using Sets.
  - `Solution03.java`: Solution for Task03 using Maps.
  - `Solution04.java`: Solution for Task04 using Queues.
  - `Solution05.java`: Solution for Task05 using Deques.

## Getting Started

To run the examples and tasks, follow these steps:

1. Clone the repository to your local machine.
2. Navigate to the `src` directory.
3. Compile the Java files using a Java compiler.
4. Run the desired example or task using the Java runtime.
